# Basic Chatbot 🤖

A simple rule-based chatbot built in Python as part of the **CodeAlpha Python Programming Internship** (Task 4).

## What It Does
CodeBot reads what you type and answers with a predefined reply:

| You type | CodeBot replies |
|---|---|
| hello | Hi! Nice to meet you. |
| how are you | I'm fine, thanks! How about you? |
| what is your name | I'm CodeBot, a simple rule-based chatbot. |
| help | Lists what it can understand |
| bye | Goodbye! (and the chat ends) |

Anything else gets a friendly "I don't understand" message.

## How to Run
1. Install Python 3
2. Run: `python chatbot.py`

## Concepts Used
`if-elif`, functions, `while` loop, input/output
